Complete Testing Workflow

1
🩸 Login as Donor (Use Your Own Account)

How to login:
• Go to the homepage
• Click "Login" in the navigation
• Select "Donor Login" from the dropdown
• Enter your donor credentials

What to do:
• Go to your donor dashboard
• Find "Donate Blood" in the sidebar
• Click "Book Appointment"
• Choose a centre (Nairobi, Mombasa, or Kisumu)
• Select a phlebotomist from that centre
• Pick a date and time
• Submit the appointment request
• Note down which centre and phlebotomist you chose!

2
💉 Approve Appointment as Phlebotomist

How to login:
• Logout from donor account
• Go to homepage → Click "Login"
• Select "Phlebotomist Login" from dropdown
• Use the credentials for the phlebotomist you booked with (see table above)

What to do:
• Go to phlebotomist dashboard
• Find the appointment you just created
• Click "Approve" to accept the appointment
• Once approved, click "Collect Sample"
• Fill in the sample collection details
• Mark the sample as collected
• The sample is now sent to the lab for testing!

3
🔬 Test Blood Sample as Lab Technologist

How to login:
• Logout from phlebotomist account
• Go to homepage → Click "Login"
• Select "Lab Technologist Login" from dropdown
• Use the lab technologist credentials for the SAME centre (see table above)

What to do:
• Go to lab technologist dashboard
• Find the sample that was just collected
• Click to open sample details
• Perform the blood test
• Mark the sample as "SAFE" (to pass it to blood bank)
• If you mark it "UNSAFE", it won't be added to inventory
• Submit the test results

4
🏥 View Blood in Inventory as Blood Bank Technician

How to login:
• Logout from lab technologist account
• Go to homepage → Click "Login"
• Select "Blood Bank Technician Login" from dropdown
• Use the blood bank tech credentials for the SAME centre (see table above)

What to do:
• Go to blood bank technician dashboard
• Navigate to "Blood Inventory" or "Stock Units"
• Look for the newly added blood unit
• Verify it shows the correct blood type
• Check that it's organized in FIFO order (First In, First Out)
• The blood is now ready to be used for transfusions!

🎉 Congratulations!

If you've completed all 4 steps, you've successfully tested the entire blood donation workflow from start to finish! This is exactly how the system will work in real-world usage.

How to Login to Different User Types

🔐 Login Steps

  1. Go to the homepage
  2. Click "Login" button in the navigation bar
  3. A dropdown menu will appear with these options:
    • Donor Login
    • Phlebotomist Login
    • Lab Technologist Login
    • Blood Bank Technician Login
  4. Click the appropriate login type
  5. Enter the username and password from the tables above
  6. Click login and you're in!

💡 Pro Tip

Keep this guide open in a separate tab or window so you can easily reference the usernames and passwords while testing!

Testing Tips & Best Practices

✅ What to Look For While Testing

User Experience

  • Are buttons easy to find?
  • Is navigation intuitive?
  • Do forms work properly?
  • Are error messages clear?

Functionality

  • Do appointments save correctly?
  • Can you approve/reject appointments?
  • Does sample collection work?
  • Are test results saved?

Data Flow

  • Does data move between roles correctly?
  • Is FIFO ordering maintained?
  • Are blood types tracked correctly?
  • Do timestamps show up properly?

Mobile Testing

  • Does it work on mobile phones?
  • Are buttons tap-friendly?
  • Is text readable?
  • Do images load properly?

📝 Report Any Issues

If you encounter any bugs, errors, or confusing parts of the system, please note:

  • What you were trying to do
  • Which user type you were logged in as
  • What happened (error message, wrong behavior, etc.)
  • Take screenshots if possible
